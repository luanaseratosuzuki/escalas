Como publicar as mudanças
  1. Monte ou edite as escalas abaixo (tudo fica salvo neste navegador automaticamente).
  2. Clique em Baixar escalas.json.
  3. No GitHub, abra o repositório → Add file → Upload files → arraste o escalas.json → Commit changes.
  4. Em 1–2 minutos o site já mostra a escala nova.
